# Meal Plan

A simple meal-planning website for organizing a five-week bulk-cooking rotation, supporting meals, quick options, and restock reminders.

Live site:
https://nanrbet.github.io/meal-plan/

## What it does

- Shows a five-week meal rotation
- Tracks bulk meal timing and overlap across weeks
- Suggests supporting meals like potato porridge
- Lists simple food options for variety
- Includes a restock checklist that stays saved on the device
- Lets you choose between color themes

## How to use

1. Open the site in a browser.
2. Select a week to view the meal plan.
3. Use the food and restock sections to plan the week.
4. Check items off as you restock or use them.

## Project status

This project is a static HTML website designed for quick, lightweight planning without needing a backend.

## Local preview

Open `index.html` in a browser, or serve the folder with a simple local web server if preferred.

Example:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/
```
